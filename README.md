# Fortuna Personal

Астанадағы Fortuna Personal клининг компаниясының қазақша/орысша сайты. Дизайн референсі — иесі берген [tez-taza.kz](https://tez-taza.kz/): ақ фон, TildaSans қарпі, көк/жасыл/қызғылт тақырыптар, үлкен баннер, 7 қадамдық сауалнама, қызметтер, прайс, қосымша қызметтер, пікірлер, команда бағыттары, галерея, FAQ, байланыс және карта.

Код HTML/CSS/JavaScript арқылы жаңадан жазылған. Tilda формалары, басқа компанияның байланыстары, аналитикасы, жалған кепілдіктері және 24/7 туралы мәлімдемелері көшірілмеген.

## Іске қосу

Node.js 20+:

```sh
npm start
npm test
```

Алдын ала қарау: http://127.0.0.1:4174. GitHub Pages-ке арналған файлдар `dist/` ішінде. Сыртқы framework, backend және ақылы сервис қажет емес.

- [2GIS пікірлері](https://2gis.kz/astana/firm/70000001066411356/tab/reviews): үш қысқа үзінді, авторларымен және толық пікірлерге сілтемемен берілген. Өзге компанияның пікірлері көшірілмеген.
- Команда бөлігінде бастапқы сайтта көрсетілген жұмыс бағыттары ғана сипатталған. Қазіргі қызметкерлер деп нақты адамдардың есімдері, тәжірибесі немесе жұмыс саны ойдан қосылмаған.

## Өтінім және калькулятор

7 қадам: нысан → қызмет → аудан → қосымша жұмыс → уақыт → алдын ала есеп → байланыс деректері.

Калькулятор тек нақты м² тарифі берілген паркинг пен жөндеуден кейінгі кіреберісті есептейді. Басқа қызметтерге жеке есептеу сұралады. Қосымша жұмыстардың құны ойдан қосылмайды. Алдын ала есеп соңғы оферта емес; баға мен уақытты менеджер растайды.

Форма хабарлама дайындап, алдын ала қарау терезесінде WhatsApp сілтемесін көрсетеді. Клиент WhatsApp-ты ашып, «Жіберу» батырмасын өзі басады. Автоматты хабарлама, бронь, төлем немесе серверге форма жіберу жоқ. Аты, телефоны, мекенжайы тек бет жадында болады, localStorage-қа сақталмайды. Тек таңдалған тіл сақталады. Карта — OpenStreetMap iframe.

## Фотолар мен қаріп

- Логотип: компанияның ашық Instagram профилі.
- `fortuna-work-1.jpg`, `fortuna-work-2.jpg`: 2GIS-тағы компания фотолары.
- `work-*.jpeg`: компанияның бастапқы сайтындағы материалдар.
- Үлкен баннер және қызмет суреттері: пайдаланушы берген референстегі иллюстрациялық материалдар. Олар Fortuna Personal-дың нақты жұмысын дәлелдейтін фото ретінде көрсетілмейді.
- Қаріп: TildaSans, ресми Tilda CDN. Барлық қолданылатын материал жергілікті `assets/` ішінде.
- Толық сурет дереккөздері: `asset-sources.json`.

`prepare-assets.mjs` — материал дайындау скрипті. Instagram суретінің уақытша CDN сілтемесі қайталама жүктеуде мерзімі өтуі мүмкін; жарияланған сайт жергілікті көшірмені қолданады.

## Өзгерту

- `dist/content.js`: екі тілдегі барлық мәтіндер мен қызметтер.
- `dist/domain.js`: телефон, компания деректері, расталған тарифтер, есептеу және хабарлама логикасы.
- `dist/style.css`: референске сәйкес дизайн және responsive нұсқалар.
- `dist/app.js`: сауалнама, тіл, слайдер, формалар және WhatsApp өтінімі.
- `dist/assets/`: логотип, фото және қаріп.
